# solveGuard pure-function test vectors
#
# Independent semantics-critic vectors for the extractor's pure guarded_call
# derivation (ctxclang::solveGuard). Each vector is a synthetic mapped graph;
# expected outputs state the specification semantics of
# docs/bend2/semantic-context-spec.md (guarded_call, denial routes, cut set),
# never the current implementation's behavior. The remote driver compiles
# against the extractor sources and prints one result block per vector.
#
# Vector grammar (one vector per `vector` directive, blank-line separated):
#   vector <id>
#   entry <blockId>            entry block id
#   callblock <blockId>        block holding the selected effect call
#   call <callId>              selected effect call identity
#   accepted <true|false>      claimed accepted polarity (whole condition)
#   decisionblock <blockId> <leafId>   one line per decision block, in leaf order
#   node <blockId> [return <returnId>] [exit] [calls <id,id,...>]
#   edge <from> <to> <label>   label in {true,false,nonDecision}; index = order
#   expect derived <true|false> [reason <text>]
#   expect cutedges <comma indices in ascending order | empty>
#   expect route <denial-edge-index> leaves <leaf=outcome,...> \
#          returns <returnId> calls <id,...>
#     (denial-edge-index: index of the denial exit edge whose target starts the
#      route; leaves: leaf outcome pairs along the route including the denial
#      edge's own leaf outcome; calls: intervening call ids in traversal order)
#   expect accepted-intervening <id,...>
#
# A vector whose expect block states derived=false with a reason token pins a
# refusal; the reason token must name the failure class in the output.
