`GUIDE.md` is the language reference (the same text `bend guide` prints). `EFFECTS.md` documents the

## Toolchain

| | |
|---|---|
| Version | Bend 2.0.25, released 2026-09-21T17:52:42Z |
| Installer | `toolchain/install-2.0.25.sh`, sha256 `94b259043a341acbfb11e99559c56b518bfb1d6733227f1e6af595ec954ab29e` |
| Release asset used here | `bend-2.0.25-darwin-arm64.tar.gz`, sha256 `c5bb22ba029d5909da9c6db82aa037278a66d1cf8a5572f433879f7dcd866c31` |

The installer is generated by the project's release tooling and carries the sha256 of each release
archive, so the script served by `bend-lang.com` vouches for the archive served by GitHub. Install
command used on this host:

```sh
mkdir -p .bend
curl -fsSL -o .bend/install.sh https://bend-lang.com/install.sh
BEND_HOME="$PWD/.bend" BEND_NO_TELEMETRY=1 sh .bend/install.sh
```

`BEND_HOME` places the toolchain at `<worktree>/.bend/` (binary at `.bend/bin/bend`, language
reference at `.bend/guide/`), which keeps the install inside the checkout. `.bend/` is untracked.
`BEND_NO_TELEMETRY=1` suppresses the installer's daily version check against `bend-lang.com`.

The installed `.bend/guide/GUIDE.md`, `.bend/guide/EFFECTS.md` and `.bend/guide/SHADERS.md` are
byte-identical to the vendored files above, so the binary on this host and this pin describe the same
language. Rust is not required: the release archive holds a native binary, `bin/bend`. Building a
program into a native executable needs a C compiler; Apple clang 17 is present here, and
`examples/toolchain-sanity.evidence.md` records the observed results for check, run and build.

## Reading this from a lane worktree

A worktree based on `bend2-rewrite` holds these files directly. Any other worktree of this
repository reads them from the branch, for example:

```sh
git show bend2-rewrite:docs/bend2/reference/upstream/guide/GUIDE.md
```

## Version policy

A claim in `docs/bend2/` cites this pin, and a capability the pin lacks is reported as absent at
this pin. Moving the pin is the operator's decision; a lane that finds the pin stale reports the gap
rather than re-pinning on its own.
