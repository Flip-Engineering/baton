# Pure Bend2 implementation audit and rewrites

The operator assigned this Ensemble to audit Baton for behavior implemented in languages other than Bend2, and to design, analyze, specify, implement, and qualify rewrites into pure Bend2. This is a broad, self-directed assignment. Use actual source and product contracts to choose the work. Read AGENTS.md and the applicable project instructions.

Audit the complete product and its delivery path: coordinator policy and state, native harness adapters, CLI and MCP surfaces, compiler and REPL integration, browser interface, packaging, installation, build tools, test support, and repository automation. Include C, Python, JavaScript, TypeScript, shell, and other implementation languages. Distinguish authored product behavior, host operations, generated artifacts, third-party packages, and fixtures using concrete source references. Every exception to a pure Bend2 rewrite needs a specific language or platform requirement and a design that minimizes foreign behavior. Investigate ways to express the behavior in Bend2 or generate the required target representation from Bend2. Do not assume an existing language boundary is necessary.

Baton is an opinionated product. Required features and dependencies ship through the normal archive and installation. Never turn a rewrite into an optional integration, feature flag, separate maintained implementation, or reduced product surface. The REPL language is Bend2 only. Preserve canonical Bend2 parsing, type and affinity checking, effects, persistent definitions and bindings, and exact user-visible semantics.

Work in the assigned isolated Git worktrees. Preserve the source snapshot and record every source pin. Produce a source inventory, a rewrite design and specification, implementation commits, and validation evidence. Keep claims separate from executed checks.
