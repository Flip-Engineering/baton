# Phase 50 GLM Spec Review — 2026-07-13

## Verdict

**REVISE** — Phase 50 is specified but not implemented. The spec (`spec/phase50/cairn-scratch-correction-oracle.md`) defines a complete contract for Scratch correction and independent oracle operations, yet the implementation layer entirely lacks the required surfaces. Three critical gaps exist: (1) no `spawnScratchOracle` or `scratch_oracle` command exists in `coordinator.mjs`; (2) `causal.correct_scratch` and its release/supersede/retract actions are absent from `coordination-store.mjs`; (3) `knowledgeScratchCorrectionPolicy` validation is missing from `cairn-run-scorecard.mjs`. The spec's SC1-SC12 cannot be verified against code that does not exist.

## P0-P1 findings

1. **[P0] Missing spawnScratchOracle implementation** — Spec SC2 defines `Coordinator.spawnScratchOracle(scratchFactId, harness, opts)` accepting active `grounding:'derived'` Scratch facts with explicit harness/model/effort. Neither `coordinator.mjs` (reviewed through line 1646) nor the transport adapters expose this method. The `spawnReview` path exists only for completed captured tasks (line 1118), not immutable derived Scratch facts. **Correction**: Add `spawnScratchOracle` method that validates derived grounding, snapshots the fact into a worker Brief, and enforces SC3's independent harness/model family requirement.

2. **[P0] Missing causal.correct_scratch operation** — Spec SC5-SC8 define `causal.correct_scratch` with three actions (release/supersede/retract) requiring Phase 49 qualified targets, derived-oracle evidence, and atomic invalidation. `coordination-store.mjs` implements Phase 49 promotion (lines 2100+) but contains no correction path. The knowledge promotion code (`promoteKnowledgeBatch`, line 286) cannot handle derived fact release or supersession. **Correction**: Implement `correctScratchKnowledge` in coordination-store that (a) validates SC6 target qualification, (b) checks SC4 oracle evidence chain, (c) derives SC7's safe projection, (d) atomically invalidates per SC8, and (e) records bounded contamination.

3. **[P0] Missing knowledgeScratchCorrectionPolicy validation** — Spec SC1 requires immutable correction policy with `repoId`, `minScratchReaders`, `maxScanEvents`, `maxAffectedReads`, `maxEvidenceRefs`, `maxBatchBytes`, `maxResultBytes`. `cairn-run-scorecard.mjs` validates `knowledgePromotionPolicy` (lines 73-82) but lacks any correction policy check. The capability card (`card()` method, lines 86-103) cannot advertise `causal.correct_scratch` without this authority. **Correction**: Add `knowledgeScratchCorrectionPolicy` constructor validation matching the promotion pattern, requiring agreement with audit/promotion repos and reader thresholds.

4. **[P1] Spec contradicts implementation on derived grounding** — Spec SC2 requires `spawnScratchOracle` accept `grounding:'derived'` Scratch facts. However, Phase 49 SP3 explicitly quarantines `grounding:'derived'` facts from promotion, and `coordination-store.mjs` line 2107 shows only `grounding:'observed'` creates Findings. The spec never explains how a derived fact becomes eligible for correction without promotion. **Correction**: Either (a) add SC13 stating "derived facts eligible for correction bypass Phase 49 promotion quarantine" with explicit audit trail, or (b) require derived facts first pass through a qualified promotion path before correction eligibility.

5. **[P1] Missing transport surface for scratch_oracle** — Spec SC11 requires authenticated web/MCP `scratch_oracle` commands with parity to direct orchestration. `web-northbound.mjs` `ARG_FIELDS` (line 16) and `mcp-northbound.mjs` `TOOL_DEFINITIONS` (line 86) list no `scratch_oracle` tool. The `COMMAND_CAPABILITY` map (web line 9, mcp line 9) lacks this permission class. **Correction**: Add `scratch_oracle` to both transports with schema exposing `scratchFactId`, `harness`, `model`, `effort`, `modelPolicy`, and appropriate capability mapping.

## Required contract corrections

1. **Resolve derived grounding eligibility gap** — Spec SC2 accepts `grounding:'derived'` facts, but Phase 49 SP3 excludes them from promotion and no alternate qualification path exists. **Add**: SC13 "Derived Scratch facts acquire correction eligibility when (a) their producer task has a durable resolved route tuple, and (b) a `scratch.fact_posted` event at or before the observation boundary records the fact as active." This closes the quarantine-to-correction path without violating Phase 49's promotion constraints.

2. **Clarify contamination projection scope** — Spec SC8 states "bounded contamination projection" without defining what knowledge reads constitute "affected." **Replace**: "records the exact earlier knowledge-read events affected by that invalidation" with "records all `knowledge.read` events at or before the pinned boundary whose `nodeId` or `edgeId` equals the target Finding ID or any edge referencing it, up to `maxAffectedReads`." This makes the contamination bound explicit and testable.

3. **Fix replay determinism for observedSeq default** — Spec SC8 states "defaults to the coordination tail at invocation start," but wall-clock tail values make replay non-deterministic. **Add**: "Replay refuses when the caller-supplied `observedSeq` predates the pinned boundary in the receipt." This ensures historical correction events replay against exactly their observation window, not a moving tail.

4. **Define maxAffectedReads enforcement** — Spec SC6 lists `maxAffectedReads` in policy but SC8 never states what happens when exceeded. **Add**: "When affected reads exceed `maxAffectedReads`, correction fails with `causal_correction_oversize` and no append." This matches the max+1 refusal pattern used elsewhere (Phase 49 SP6, SC9).

5. **Specify oracle worker brief isolation** — Spec SC2 states the snapshot is "detached, immutable, and bounded" but doesn't mandate the worker cannot request access to live repository state. **Add**: "The oracle worker Brief includes no repository write authorization and the worker is forbidden from `Edit`, `Write`, or repository-mutating `Bash` tools." This prevents an oracle task from inadvertently contaminating the graph it's meant to passively review.
