# #169 kernel-honesty audit — the systematic pass over the kernel

Scope: baton's KERNEL layers, hunting exactly two defects — (a) silent or approximate
authority/recovery behavior (the mechanism acts, but the record doesn't say what/who/why, or a
recovery that could be automatic is manual), and (b) refusals that don't name their
holder/cause/next action. This mirrors the #147 surface audit one layer down.

Method (same discipline as `control-surface-audit-2026-08-13/audit-brief.md`): every claim cites
`file:line` read this session; NUL files (`coordination-store.mjs`, `application.mjs`) were read
via `grep -an`/`sed -n` only (their NUL bytes are cache-key separators at
`coordination-store.mjs:16604` and `application.mjs:626`, not corruption — non-finding).
Read-only outside this deliverable; no clocks; no redesign — findings, not architecture.

## Ranked fix list

1. **Capacity reservation refusals — name free/floor/reservations** (`worktree-capacity.mjs:399–402`). Highest orchestrator cost: this is the "floors invisible until dispatch refuses" class, and the numbers are already in scope at `:378–391`. Fix is pure payload plumbing. (instance 4)
2. **Stale writer-lease recovery — make it record what it did** (`coordination-store.mjs:1319–1324`; `resident-authority.mjs:147, 175, 215`). Silent authority reclamation is the core (a) defect; `publish()` already does this right at `resident-authority.mjs:384, 412` — extend the same flag to the lease path. (instance 1)
3. **`waves.*` pre-gate — close the seam** (`application.mjs:12560–12603`). Lease-holders bypass the recursive gate; the #12 partial mitigation misses `waves.send`/`waves.progress`/`waves.list`. Re-pin the drifted anchors while here. (instance 5)
4. **`run.result()` — never report bare `empty` over an existing pin** (`application.mjs:10560–10615, 10823, 11122, 11548`). The AX-wave report is a correctness-of-record failure, not a polish issue. (NEW)
5. **#148 credential lifetime — surface `sessionExpiresAt` + a renewal verb** (`application-deployment.mjs:1758`; `resident-authority.mjs:336–342`). The 25-blind-retry incident is the direct cost. (instance 2 / #148)
6. **Base-commit pinning — sideband ref `refs/baton/base/<taskId>`** (`worktree.mjs:1080, 1113, 1005–1006`). Makes the base commit recoverable independent of the owner JSON. (#168)
7. **Fenced-principal refusal — name the fence event** (`coordinator.mjs:3727, 6685, 7273–7416`; `application.mjs:2779`). Record `bumpCause`, thread `{attempted, current, cause}` to the surface. (instance 2)
8. **`_authorize` collapse — name command + missing capability** (`application.mjs:3214–3221`). The hook must return the capability for the refusal to name it. (NEW)
9. **`run.attention.watch` — stop paging EMPTY on foreign scope** (`application.mjs:13077–13091`). Add resolve-then-authorize as the sibling ports do. (NEW)
10. **Stale `index.lock` — typed refusal with holder/recovery** (`worktree.mjs:1205–1227`). Match the deployment snapshot's sideband discipline or detect and coach. (NEW)
11. **`complete()` — return an explicit `quiescent`/`parkedReason`** (`application-client.mjs:501–524, 1089–1112`). Enforceability requires a server-observable marker, but the ambiguity is fixable client-side first. (NEW)
12. **Manual publication-conflict refusal — name the holder** (`resident-authority.mjs:380–383`). (instance 1)
13. **`coordination_writer_busy` — name the holder** (`coordination-store.mjs:1290, 1317, 1326`). Lowest cost; the payload already has `{pid, pidStart, acquiredAt}`. (instance 1)
14. **Dead-owner reaps — record who/why and stop discarding `removed`** (`worktree-capacity.mjs:535–560, 307–330`; `index.mjs:1044–1045`). (instance 4)

## Non-findings and recorded judgment calls

- **Replay is honest.** No approximate replay or silently-skipped record class found; the `offset % 2` filters are torn-batch validations that fail closed (`coordination-store.mjs:2229–2231`), and the checkpoint `'unusable'` fallback replays from 0 with the state named (`:1485`). (instance 3)
- **The eight facade direct ports are NOT an authority gap.** Fresh read confirms seven of eight call their own `_authorize` — `messageSend:13025`, `messageReceipt:13052`, `scratchpadRead:13097`, `scratchpadElevate:13146`, `boardPost:13159`, `boardRead:13229`, `knowledgeSeed:13252`. Only `run.attention.watch` (`:13077–13091`) lacks one, and that is called out separately above. (This corrects an earlier over-claim; recorded.)
- **NUL bytes** at `coordination-store.mjs:16604` and `application.mjs:626` are cache-key separators (`${a}\0${b}`), not corruption — no finding.
- **`waves.start` is the least-severed seam** of the pre-gate set: it delegates to `start()` which runs `_authorize('run.start', …)` per member (`application.mjs:4561`). `waves.send`/`waves.progress`/`waves.list` have no such backstop.
- **Instance-number mapping** (1–5) is a judgment call because the issue body was unreachable; see Seed-row provenance above. If the issue's numbering differs, the layer→finding mapping holds and only the instance column relabels.
