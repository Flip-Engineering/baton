# Phase 84 Context successor-Wave live dogfood

Run from the repository root with one command:

```sh
node docs/reference/evidence/phase84-context-successor-wave-live-2026-07-18/run.mjs
```

The runner uses Baton's ordinary application API and internal deployment defaults. The caller
supplies only the audit objective, exact orchestrator-selected routes, one report path, and a fresh
direct Node verification command. Credentials, token/USD budgets, wall clocks, provider turns, export byte
limits, and worktree choreography are not caller inputs.

It starts two independent auditors in parallel, creates a pure source-grounded Context search cell,
maps that immutable cell into a separately approved successor Wave, waits for durable aggregate
settlement, retains partition reports, and then proves descendant stop/reap plus caller checkout
preservation. Native Kimi Code is preferred when its subscription is ready; otherwise the same
proof uses independent Codex high/xhigh routes and records Kimi readiness honestly.
