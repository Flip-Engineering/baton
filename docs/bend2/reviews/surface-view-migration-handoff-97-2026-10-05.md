## 3. Live-old-attempt version-change case (legacy raw absence)

Released-fca retained attempt with PENDING INPUT; the installed binary changes mid-attempt; observer loss forces receive under the NEW binary. Requirements the migration must preserve: pending input delivered (store-held), completion/report identity from the OLD stream semantics, refusal detection from `<attempt>/native.stderr`, and legacy raw absence tolerated (no new-format notes, no raw cursor semantics). Exact assertion: resumed attempt delivers the pending input, the completion report matches the old stream's terminal, the refusal marker path is honored when present, and no new-format line is required or synthesized.

## 4. Common draft (Receive97) review — selected-frame/raw distinction and continuation binding

- Items 1 and 7 (raw bytes host-owned opaque; selected frames reference original source ranges; never reuse selected-file offsets as raw cursors) are correctly drawn and match my caller traces: the file-offset consumer (caller 6) is the concrete legacy case that motivates the two-coordinate-space rule.

One addition from the caller traces: derived replay must be a PURE path — the production consume WRITES the OUTPUT_LOG during replay, so the view replay cannot reuse the writing consume loop without side effects; Interfaces needs the pure frame-step functions (the 9c12 loop-call wrappers' inner calls) without their store/appends.
