root reviewed, acknowledged, landed and published its commit through the
coordinator. The root verified the advertised remote ref with `git ls-remote`.

## Landing and publication

The root used these coordinator operations, where `REPO` is the scratch clone:

```sh
baton2 state.db worktree root-docs
baton2 state.db workers
baton2 state.db ack root-docs-turn root RECEIPT
baton2 state.db land root-docs REPO day-target
baton2 state.db push REPO day-target scratch
```

The root reported `landed` and `pushed`. The target branch and the advertised
`refs/heads/day-target` both resolved to
`693f7612067e33ab107ac05bf088485e98ed3559`. The declared remote `scratch`
was a local bare repository named `published.git`. The root checked the remote
configuration and read its advertised ref with `git ls-remote`. Publication
in this run was to that local remote. The repository's network publication
remains the external root's operation.

The final root inbox was empty. The worker process exited normally; after the
root's native turn completed, the foreground root poll process was stopped.
The native worker session, branch and workspace were retained.
