# Baton2 1.0 scope

Baton2 1.0 coordinates native coding agents on macOS 27 arm64. Git supplies
repository operations. Native harnesses provide their own authentication and
conversation storage. The project source uses [Apache License 2.0](../../LICENSE);
upstream Bend compiler/runtime and reference notices remain separate.

## Supported workflow

The qualified workflow uses a subscription Codex Principal Conductor, an OMP
Kimi K3 Associate Conductor, and concurrent OMP DeepSeek Flash and Muse Spark
1.3 contributor Players. It includes native guidance, saved-conversation
corrections, review, checks on target and candidate trees, and both landing
levels. Separate [native Git qualification](native-git-qualification-2026-10-02/README.md)
exercised publication to an owned local bare remote. [Harness setup](harness-setup.md) records launch
paths and login requirements. Codex uses the ChatGPT subscription login.

Conductors message descendants; subordinate agents message their immediate
Conductor. Peer messaging requires a designated tight Ensemble, and Conductor
peers share a hierarchy depth. New Ensembles default to loose coupling.
[Messaging](messaging.md) describes admission and accepted retries.

Agents record and review knowledge in session scopes. Explicit promotion
notifies the destination owner, who decides distribution to further Ensembles.
The [knowledge qualification](knowledge-context-2026-10-01.md) records shared
retrieval and retrieval from a fresh native conversation.

## Recovery and host effects

Retained receive preserves a running native turn across observer loss, keeps
output and completion, continues queued input and delivers the parent report.
Separate direct-turn process-loss qualifications resumed Codex's recorded
conversation and exercised OMP's fresh fallback when its conversation was
missing. Both direct-turn interruptions preceded a file edit. [Recovery evidence](native-recovery-qualification-2026-10-02/README.md)
records the exact interruption points and host boundaries.

Keeper loss, host restart and power loss require separate qualification. Agent
branches and workspaces remain available after completion and landing; cleanup
requires establishing that their work is no longer needed. [Architecture](architecture.md)
records the supported state and ownership contracts.

Bend compilation verifies imported operative laws. Runtime checks exercise
SQLite, process, Git and native-harness effects. [Source acceptance](../../CONTRIBUTING.md)
requires all three gates on the exact committed tree.

## Distribution

A versioned archive contains the native executable, source/build manifest,
complete gate logs, project license and attribution, and upstream Bend notices.
Its SHA256SUMS file advertises the archive digest. [Artifact procedures](native-artifacts.md)
describe packaging and extracted use with the recorded build path unavailable.

The version label identifies the builder's requested release. The actual remote
tag, release assets and downloaded checksums establish publication. The
[readiness record](readiness.md) retains qualification results and outstanding
release checks.
