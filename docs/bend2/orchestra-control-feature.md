# Native Orchestra control

## Purpose

Baton2 makes its team structure clear through ordinary native operations. An
agent can discover how to build, inspect and direct teams from command help,
MCP tool descriptions and its native harness briefing.

## Structure

A Principal Conductor coordinates the Orchestra. It can directly manage
Ensembles and delegate to multiple Associate Conductors. An Associate Conductor
can manage Ensembles and delegate to further Associate Conductors.

An Ensemble is a coordinated team with a Conductor owner and declared coupling.
Sections group that Ensemble's Players by capability. Development, research and
criticism use the same structure; a review Ensemble can have separate Sections
for feature coverage, architecture, laws, security and agent experience.

Each Player has its recorded parent, harness, model, workspace and branch.
Conductors assign work and direct reports through the existing native delivery
and landing operations. Independent Players can work concurrently.

## Native use

Help and tool descriptions explain the relationship among recruitment,
Conductor responsibility, Ensemble ownership and Section membership. They show
how to construct direct and hierarchical teams, including several Associate
Conductors, and identify the valid next operation when setup is incomplete.

Native inspection connects parentage, owned Ensembles, Sections and Players in
one readable view. It includes recorded routes, current work and pending input
needed to direct the team. Structured results retain stable, inspectable fields.

A native briefing identifies the agent's responsibility, immediate Conductor,
applicable Ensembles and Sections, and permitted communication routes. Agents
can discover team construction and inspection through the same native control
surface they use to dispatch, steer, review and land work.

The implementation reuses current session, role, Ensemble and Section records.
Setup operations preserve recorded assignments and expose retry or refusal
conditions. Coupling remains explicitly declared. Native command and MCP
operations apply the same admission rules and return the same facts.

## Acceptance

An agent with only the installed tooling and its briefing can construct and use
an Orchestra with multiple Associate Conductors, several Ensembles and several
Sections, including a critic Ensemble. The run demonstrates concurrent
dispatch, scoped messages, parent reports, inspection and reviewed landing.

Every change carries operative laws over the real functions and the appropriate
host-effect checks. Readable and structured views agree with stored parentage,
ownership, membership and active work, including incomplete setup and retained
historical sessions.
