## Evidence rules

1. Preserve requested route separately from observed native model/session fields. Current Codex stdout carries thread identity and usage; model/effort are requested values unless independently observed. Original owned Codex session context confirmed model/effort. Missing Muse usage remains unknown.
2. Count logical commands and native actions from their actual actor/provenance. A compound shell tool call may invoke several commands. The current extraction retains command frames and check/landing receipts; it does not infer a complete coordinator-command census from substring matches.
3. Retain failed startup, refusal, check and provider records. Original 503 and current wrong-harness exit are different observed outcomes. A subsequent useful result does not replace either.
4. Treat process records and sampled presence as separate evidence. Only completed wait receipts give full child lifetimes. Simultaneous non-zombie samples establish observed overlap during their recorded interval.
5. A source-level explanation is an inference until the relevant path and runtime receipt agree. Earlier effective environment filtering remains unobserved. Final native root tool frames explicitly bind the common capacity namespace for root landing and final checks; no specific OMP filtering cause is asserted.
6. Keep UTF-8 byte lengths, decoded character counts, exception-string contents and file framing distinct. Preserve authored incorrect fields alongside corrected measured quantities.
