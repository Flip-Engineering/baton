# Baton validator law inventory: closed shapes, authorization boundaries, swarm permission model, contribution and landing contract

Provenance: audit lane bend2-laws-validators, supporting issue #539 mandate part 3 (docs/bend2/laws.bend, docs/bend2/laws-trace.md). Audited revision: bc2e4fcd072e9edce21f94ee2ea8bb938c409f9b, clean worktree. Every source and test anchor below was read at that revision; when the branch has moved, re-anchor with `git show bc2e4fcd:<path>` before citing a line number.

## Purpose

docs/bend2/laws.bend encodes Baton's invariants in Bend2. This document is the seed inventory for the swarm-facing validator families: the closed shapes every surface shares, the authorization boundaries between seats and checkouts, the swarm permission model, and the contribution and landing contract. Each law names its enforcement point in impl/src and the test in impl/test that pins it, so laws-trace.md can cite both sides.

## Row format

Each row reads: ID name — behavior. Source: file · symbol · lines. Test: file · "test name" · line. Classification. Bend2: encoding candidate.

Classification `extracted` means the source enforces the law and a test pins it. `extracted-untested` means the source enforces it and no pinning test exists in impl/test at the audited revision. `proposed` means the law is absent and is a candidate for the Bend2 encoding.
