# Corrections from review 28

1. resolve.mjs no longer passes a URL to path arithmetic: adapterPathFor() converts with fileURLToPath for `file:` inputs, and both contextRootFor and createRequire consume the converted path. contextRootFor is no longer computed from an unconverted URL, so realpathSync(contextRoot) cannot see a `file:` prefix. The staging tree the test creates deliberately contains a space ("stage-<hex> (with space)") so a URL-with-escapes resolution is exercised.
2. Test staging copies the real dependency closure (package.json + lib/) into <stage>/libexec/baton2/context/node_modules/typescript, and places an ambient bait package at <stage>/node_modules/typescript whose lib/typescript.js throws. The engines test asserts the reported identity path is inside the package context root and that the bait string appears nowhere in the frame. No symlink to an external install remains.
3. Record-builder checks run in a Node fixture (fixtures/consumer/record-contract.mjs) that imports the real ESM builders and reports, per case, whether the builder refused. Retained child artifacts: record-contract.{stdout,stderr,status.json}. Cases: empty module digest, empty snapshot, negative range, empty callee declaration digest (all refused with TypeError) plus one complete record and one dynamic-SQL record accepted.
4. The capture regression driver takes its root and result path from environment variables (no `-e` positional ambiguity) and the parent reads the result file before any cleanup; the workspace is retained under the evidence directory instead of a TemporaryDirectory.
5. No subprocess deadline remains (the 300/120/900 second values are gone). Every spawn writes <label>.argv.json, .stdin, .stdout, .stderr and .status.json {returncode, signal, spawnError, cwd} into BATON2_CONTEXT_EVIDENCE (default <worktree>/.scratch/context-typescript-evidence), and nothing is truncated in writes or in assertion messages. An exit-1 run requires no result frame and is asserted to publish none while retaining stderr; only exit 0 and exit 2 must carry exactly one frame.
6. query.mjs runs the producers first and computes the snapshot identity afterwards from capture.descriptors() over the complete closure, then binds that identity into every published fact, ref, limit and nested record (bindSnapshotId) and refuses to publish if any marker remains (assertSnapshotBound). protocol.mjs additionally rejects a ref whose snapshotId differs from the envelope identity and a fact record whose snapshotId differs from it. A new test (projection-time capture) queries a definition whose declaration lives in another file, asserts that file is present in snapshot.inputs, that all refs and records equal the envelope identity, and that editing that imported declaration changes the snapshotId on the next run.
