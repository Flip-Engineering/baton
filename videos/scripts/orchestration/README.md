# Orchestration workflows (this session's)

Workflow scripts the orchestrator ran for CLOTHING c1 and HUMAN c8 on 3 Oct, kept here so a later session can resume them.
They take `args: { house, fabric }`: `house` is `house.txt` (the shared brief), `fabric` is `fabric_report.txt` (CLOTHING's
fabric builder's final report; only `wf_cloth_finish.js` uses it). Resume a run with
`Workflow({ scriptPath: "<abs path to the script>", resumeFromRunId: "<run id>", args: {...} })`: agents that finished
return cached results (same session only); a new session re-runs them (they continue from the files on disk).

`snap.sh "<message>"` is the orchestrator's WIP snapshot: syntax-checks changed JS, stages code plus each studio's NOTES, boards and
tools (never stills, dev, proof, scratch or refs_local), unstages any new photograph, commits with the attribution lines and pushes. It runs
every ~5 minutes while builders work, and at once when a builder writes 'COMMIT PLEASE' in its NOTES for the farm.
